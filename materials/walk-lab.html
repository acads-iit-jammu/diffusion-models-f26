The Walk Lab

Toss a coin n times, adding +1 for heads and −1 for tails. Forward, the distribution takes shape — not because the middle paths are likelier, but because there are more of them. Backward, name where the walk ended and watch path space collapse to the paths still consistent with it.

Act I · the forward processCounts pile up, and that is the distribution

Every node is a position after t steps; its label is the number of distinct paths that reach it. Node size is that count as a share of its own column. The bars on the right share the same k axis — so the distribution is literally the column of counts, turned on its side.

Lattice · path counts N(t,k)P(S_t = k)

Every path is equally likely. All of them have probability 1/2ⁿ, so ranking paths by probability gives one enormous tie. What differs between endpoints is only how many paths land there.

Act III · the reverse processRunning it backwards is counting

Of the paths that end where you said, what fraction took +1 last? Nothing has to be learned or approximated — count them. Apply the answer repeatedly and you have sampled a path backwards out of a single number.

The reverse step

The consistent paths

Counts are exact binomial coefficients; probabilities are N(n,k)/2ⁿ. The backwards sampler uses P(last = +1 | S_m = k) = j/m with j = (m+k)/2, which draws uniformly from the consistent paths — the same reverse step a diffusion model has to learn when the counting is no longer possible.
