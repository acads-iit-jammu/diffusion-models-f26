2. Score ascent concentrates. Langevin sampling preserves spread.

Both clouds begin with the same 1,200 standard Gaussian draws. The target score is s(x) = −x. The left cloud follows the exact ascent ODE. The right cloud uses Euler–Maruyama with fresh noise.

Ascent: dx/du = −x   ·   Langevin: x ← (1 − h)x + √(2h)z
Ascent histogramLangevin histogramTarget N(0,1)

Both histograms share axes. A narrow spike has a high density; the target curve can look small beside it. Finite-step stationary variance is 1/(1 − h/2); this is a limiting value, not necessarily reached by time 6.

3. One score, two samplers, the same target density path.

Data are an equal mixture of N(−2, 0.35²) and N(2, 0.35²). Forward noising follows dX = −X dt/2 + dW. Generation starts at T = 8 and moves toward t = 0, with reverse clock τ = T − t.
